# 税务案头

中国大陆一级市场股权投资税务知识问答的小范围测试前端，直接调用已发布的阿里云百炼知识问答服务。

访问：<https://allenruan92.github.io/tax-law-chat/>

## 使用

1. 打开网页，点击「连接设置」，填入百炼 API Key。应用 ID 已预设。
2. 提问后可继续追问；页面会携带最近最多 10 轮完整问答，总上下文按 24,000 字符截取。这是前端会话管理，不是长期记忆。
3. 点击「复制体验链接」，私下发给试用同事。同事打开后会导入连接信息，不会收到你的聊天记录。
4. 可停止生成、复制回答、导出 Markdown，或新建对话。刷新保留当前标签页记录，关闭标签页后不保证保留。

## 知识库管理

点击侧栏「知识库管理」（手机上为 ▤ 图标）。管理目标固定为 `tax-law-poc`（`uwohowhkia`），不会随连接设置中的问答应用 ID 改变。

- 选择或拖入文件，点击「上传」。页面依次完成上传凭证申请、文件传输、登记、解析与索引；显示「可检索」后再提问验证。面板打开时每 5 秒自动刷新，支持分页。
- 本页支持 PDF / DOC / DOCX / PPT / PPTX（≤150 MB）、TXT / MD / Markdown / HTML / XLS / XLSX（≤10 MB）、PNG / JPG / JPEG / BMP / GIF（≤20 MB），每批最多 10 个。页数等进一步限制由百炼校验；扫描件的解析质量需自行核对。
- 文件会上传到阿里云百炼数据中心，并加入当前知识库。解析、向量化、存储及后续问答可能产生费用，以账号实际计费为准。文件名建议保留法规日期、文号和有效版本。
- 「停止上传」只中断前端当前操作，不回滚已上传或登记的文件。网络中断后先刷新列表核对，避免重复提交；已登记但未提交入库的任务支持「重试入库（不重传）」。
- 「移除」需要核对文件名、勾选并确认。它删除当前知识库中该文档的索引与切片，影响所有试用者；**数据中心源文件保留**，没有永久删除源文件或整个知识库的入口。同步可能延迟约 30 秒。
- 上传任务的非敏感状态保存在当前标签页，刷新后可继续查询已提交的入库任务；原始文件不保存在浏览器存储。清空任务记录只清本地列表，不删除云端文件。关闭页面会打断尚未完成的传输。

这是共享管理权限的 POC，没有用户角色区分。Key 必须有该工作空间的管理权限，仅能问答的 Key 可能返回 401 / 403。列表、入库和移除由浏览器直连百炼；上传凭证和登记接口受跨域限制，改由本账号的 FC 代理。文件用临时签名地址直接上传 OSS，API Key 不发送给 OSS。

## 分享与费用

这是用户接受共享 Key 方式后制作的验证版本，没有用户账号或角色区分。GitHub Pages 链接可公开访问；API 调用费用由 Key 所属百炼账号承担，按应用实际调用的服务计费。上传管理版使用 FC 小型代理，其函数调用和运行资源另按阿里云实际用量计费，无预置常驻实例。

Key 不写入仓库或静态代码，仅保存在当前标签页的 `sessionStorage` 中。体验链接的 `#access_key=…` 包含 Key，打开后会从地址栏移除；拿到链接或使用网页的人仍可提取 Key。Key 不一定只授权当前应用。不要公开发布体验链接；结束测试请在百炼撤销或更换 Key。网页「清除 Key」只清本地，不会撤销已分享链接。

浏览器直接向百炼发送问题及近期上下文。管理版会将 Key 和上传元数据发送到账号内的 FC 代理，代理仅保存 Key 的摘要用于校验，不记录明文。网页不使用第三方统计、字体或脚本。GitHub Pages 在部分大陆网络下可能不稳定。
